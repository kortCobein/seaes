- **NO** completar el desarrollo pendiente de Preview, PDF, tarjetas ni editor.
- **NO** fusionar esta rama en `main`; la base WIP diverge y contiene código de una versión anterior.
- Corregir solamente errores de compilación o bloqueos evidentes de arranque, documentando cada intervención.
- El archivo `dist` resultante será una vista provisional, no una entrega final.
